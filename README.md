# CIS261_WK10_VIBE

This project is a simple Python starter app for the Week 10 "Vibe Coding" assignment.

## What it does

The script welcomes the user, asks for their study topic and energy level, and then gives a short motivational message to help them stay focused.

## Run the app

From the project folder, run:

```bash
python CIS261_WK10_VIBE.py
```

## Example

```text
=== CIS261 WK10 Vibe Coding ===
What is your name? Alex
What topic are you studying today? Python
How is your energy from 1 to 10? 8

Welcome, Alex! Let's keep the momentum going.
Today's focus: Python
Your energy is high. Focus on Python and make strong progress.
Next step: write one small task, complete it, and celebrate the progress.
```
